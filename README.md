# Караоке-баттл

Браузерная игра для хакатона «Звук» × ИТМО (17–18 октября 2026, кейс 4): поёшь фрагмент песни, получаешь оценку попадания в мелодию и ритм с объяснением по строкам, улучшаешь результат и вызываешь друзей на дуэль.

Godot рисует, JS слушает, бэкенд судит.

## Запустить игру (без Godot)

Собранная игра лежит в репозитории, в `dist/web`. Нужны только [uv](https://docs.astral.sh/uv/) и Chrome или Edge.

```bash
git clone <url>
cd GGuap_hack_oct2026/backend
uv sync                                   # только в первый раз
uv run uvicorn app.main:app --port 8000   # окно не закрывать
```

Открыть http://localhost:8000/ (микрофон, лучше в наушниках) или http://localhost:8000/?mock=perfect (без микрофона).
Открывать `dist/web/index.html` двойным щелчком нельзя: игре нужен бэкенд, а микрофону — `localhost`.

### С телефона, с живым микрофоном

Браузер даёт микрофон только на `localhost` или по HTTPS, а `http://192.168.x.x` таковым не считается. Ниже два способа это обойти.

**Способ 1. Android + Chrome по Wi-Fi.** Интернет не нужен.

1. На компьютере запустить бэкенд так, чтобы его было видно в сети:
   ```powershell
   cd backend
   uv run uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```
   Если Windows спросит про брандмауэр, разрешить доступ для «Частных сетей». Если окно не появилось, выполнить в PowerShell от администратора:
   `New-NetFirewallRule -DisplayName "Karaoke 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Private`.
   Сеть Wi-Fi в Windows должна быть «Частной», а не «Общедоступной».
2. Узнать IP компьютера: `ipconfig` → «IPv4-адрес», например `192.168.1.23`.
3. Телефон подключить к той же Wi-Fi сети. Сначала проверить, что адрес открывается: `http://192.168.1.23:8000/?mock=perfect`.
4. На телефоне в Chrome открыть `chrome://flags/#unsafely-treat-insecure-origin-as-secure`, вписать `http://192.168.1.23:8000`, выставить **Enabled** и нажать **Relaunch**.
5. Открыть `http://192.168.1.23:8000/`, нажать на экран и разрешить микрофон.

Если IP компьютера сменится, адрес во флаге нужно поменять.

**Способ 2. Любой телефон, включая iPhone, через HTTPS-туннель.** Нужен интернет, ничего ставить не надо: `ssh` уже есть в Windows 10/11.

1. Запустить бэкенд как обычно: `uv run uvicorn app.main:app --port 8000`.
2. Во втором окне запустить туннель:
   ```powershell
   ssh -R 80:localhost:8000 nokey@localhost.run
   ```
   На вопрос про fingerprint ответить `yes`. В выводе появится адрес вида `https://abcd1234.lhr.life`.
3. Открыть этот адрес на телефоне, нажать на экран и разрешить микрофон.
4. Чтобы ссылка и QR дуэли вели на туннель, а не на localhost, перезапустить бэкенд с этим адресом:
   `$env:KARAOKE_PUBLIC_URL="https://abcd1234.lhr.life"; uv run uvicorn app.main:app --port 8000`.

Бесплатный туннель живёт, пока открыто окно `ssh`, и при каждом запуске выдаёт новый адрес. Вся игра (~52 МБ) и записи голоса идут через внешний сервер, поэтому первая загрузка будет дольше.

**На телефоне:**
- играть в горизонтальной ориентации: интерфейс рассчитан на 16:9;
- петь в наушниках, иначе микрофон услышит минус из динамика;
- нужен браузер с WebGL 2, на слабых телефонах 3D-сцена может подтормаживать;
- задержка звука на телефоне выше, чем на компьютере; она подстраивается сама после нескольких дублей, поэтому первый дубль может оцениться хуже.

Обновить сборку (нужен Godot 4.8-dev7 с шаблонами Web): `powershell -ExecutionPolicy Bypass -File scripts\build-web.ps1`, затем закоммитить `dist/web`.

## Быстрый старт

Движок без Godot:

```bash
make setup
make backend
```

Открыть http://localhost:8000/dev.html. Мок без микрофона: http://localhost:8000/dev.html?mock=perfect

Игра: положить экспорт Godot в `dist/web` (`make export-web GODOT_PROJECT=<путь к проекту>` или скопировать готовый), затем

```bash
make demo
```

Открыть http://localhost:8000/. Мок без микрофона: http://localhost:8000/?mock=perfect
