# songs — как сделать песню для игры

Сеня, это твоя задача. Сейчас в игре есть только `demo` — синтетическая гамма «до-ре-ми» на 12 секунд для разработки (в ней `minus.wav` и `guide.wav`, нет `meta.yaml` и `check.json`; это не образец раскладки). Для защиты нужна хотя бы одна настоящая песня:

- **Калинка** — обязательно, к вечеру 16.10;
- **Коробейники** — если успеешь.

Работаешь в ветке `senya/songs`. Когда песня готова — `git push` и напиши Паше «готово», он проверит и смёрджит.

---

## Зачем это всё

### Что такое эталон
Эталон (`reference.json`) — это «ноты с ответами» для песни: для каждой ноты записано, **когда** её петь (время и длительность), **какой высоты** (midi) и **какой слог** («Ка-», «-лин-», «-ка»). Без эталона игра слышит голос, но не знает, правильно ли человек поёт.

Эталон нужен в пяти местах:
1. **Дорожка нот в Godot** — полоски, по которым видно, что и когда петь.
2. **Живой судья в браузере** — сравнивает голос с нотой: точки на дорожке, «попал / мимо», реакции продюсера.
3. **Итоговая оценка на бэкенде** — тон и ритм по каждой ноте, разбор по строкам и советы («вторую строку пел выше на полтона»).
4. **Автоподстройка задержки** — бэкенд ищет, на сколько миллисекунд пение сдвинуто относительно нот.
5. **Античит** — «не голос» проверяется на длинных нотах эталона, «фонограмма» — сравнением с записью голоса.

Кроме эталона песне нужны:
- **минус** (`minus.mp3`) — аккомпанемент без голоса, под него поют;
- **guide** (`guide.mp3`) — запись голоса, который правильно поёт эту мелодию. По нему `refpipe check` убеждается, что эталон совпадает с песней (правильное пение должно набирать ≥90%), и античит ловит, если вместо пения включат эту запись.

### Почему народные песни, а не любые
Так решили 8.10 (ADR-006 в `docs/40 Решения/`): народные мелодии в общественном достоянии (PD), **своя** аранжировка и **свой** голос.
- **Юридически чисто.** Репо публичное (MIT), демо публичное. У популярных песен защищены и мелодия, и текст, и запись — их минус, текст и эталон выкладывать нельзя.
- **Точный эталон из MIDI** — без ошибок нейросети.
- Калинка — И. Ларионов (1860, умер 1889) → PD. Коробейники — народная мелодия, стихи Н. Некрасова (умер 1877) → PD.

### Почему фрагмент 20–40 секунд
Продуктовое решение: на защите ~6,5 минуты, одна попытка вместе с экраном результата должна в них уложиться; дуэли и повторы — короткими раундами; бэкенд считает оценку, пока игрок ждёт. Это не ограничение техники — полные песни (и пауза к ним) после хакатона.

## Что нужно сделать

### 1. Исходники (в git НЕ попадают)
Создай папку `songs-src/kalinka/` в корне репо — она в `.gitignore`. id песни — латиницей: `kalinka`, `korobeiniki`.

| Файл | Что это | Как сделать |
|---|---|---|
| `melody.mid` | только мелодия голоса, одна дорожка, без аккордов | MuseScore: набрать мелодию → File → Export → MIDI |
| `lyrics.txt` | текст, разбитый на слоги | одна строка = одна фраза; слоги через дефис; **один слог = одна нота** (см. ниже). Настоящий дефис в слове — двойной: `пол-ным--пол-на` → «полным-полна». Отдельно стоящие тире и многоточие (`—`, `–`, `…`) приклеиваются к предыдущему слогу и нотой не считаются |
| `minus.wav` | своя аранжировка без мелодии | в том же файле MuseScore добавить аккорды / бас / ударные, выключить партию мелодии → File → Export → Audio |
| `guide.wav` | голос | записать вокал в GarageBand, Audacity или MuseScore на дорожку поверх импортированного `minus.wav` (в наушниках) и экспортировать **только голос от начала таймлайна** — тогда он совпадает с минусом сам. Запись на телефон: обрежь её начало в редакторе, пока голос не встанет ровно на минус, или измерь сдвиг и передай его в `cut` через `--guide-offset-ms` (шаг 3.4) |

Пример `lyrics.txt`:
```
Ка-лин-ка, ка-лин-ка, ка-лин-ка мо-я!
В са-ду я-го-да ма-лин-ка, ма-лин-ка мо-я!
```
Если один слог тянется на две ноты — допиши `~` как отдельный слог: `мо-я-~`.

Важно:
- `melody.mid` и `minus.wav` должны начинаться **в одну и ту же секунду** — экспортируй оба из одного файла MuseScore.
- Темп — как в минусе. Не ставь в MIDI очень короткие форшлаги (короче 1/32): они сольются с соседней нотой и `from-midi` выдаст ошибку.
- Кто поёт guide — даёт **письменное согласие** (сообщение в чате подойдёт), его имя пойдёт в `meta.yaml`.

### 3. Собрать песню
Все команды — из папки `pipeline`:
```
cd ~/huap_hack_oct2026/pipeline
```

**3.1. Ноты + текст → song.txt**
```
uv run refpipe from-midi ../songs-src/kalinka/melody.mid ../songs-src/kalinka/lyrics.txt -o ../songs-src/kalinka/song.txt --title "Калинка" --artist "нар. (И. Ларионов), аранж. huap team"
```
- `lyrics have N syllables, melody has M notes` — число слогов и нот не совпало: поправь `lyrics.txt` (разбей / склей слоги, добавь `~`). В сообщении есть номер канала и сколько нот на каждом канале — если взялась не та дорожка, добавь `--channel N`.
- `rounds onto the same beat` — две ноты слишком близко: добавь `--bpm` вдвое больше темпа песни.

**3.2. Золотые ноты.** Открой `songs-src/kalinka/song.txt`. Строки нот начинаются с `:`. Поменяй `:` на `*` у 5–15% нот — длинные ноты, кульминация. Золотая нота даёт двойные очки.

Не включай в редакторе удаление пробелов в конце строк: пробел после слога — граница слова, без него текст склеится («Калинкакалинка»).

**3.3. meta.yaml.** Скопируй пример и поправь:
```
mkdir -p ../songs/kalinka && cp examples/meta.example.yaml ../songs/kalinka/meta.yaml
```
В `../songs/kalinka/meta.yaml`:
- `voice` — `female` или `male`: кто будет петь (от этого зависит октава нот);
- `license.recording.title` — например «Калинка, аранжировка и вокал huap team»;
- `vocalists` — имя того, кто пел guide, `consent: true`, дата согласия;
- `changes` — какой фрагмент взят (например «фрагмент 0:05–0:39 из своей аранжировки»).
- для новой песни (не Калинки) поправь ещё `title`, `artist`, `license.music` (`title`, `author`, `author_died` или `folk: true`) и `attribution` — иначе песня покажется в игре под чужим названием. `title`/`artist` должны совпадать с `--title`/`--artist` из шага 3.1.

Лицензии, которые проходят: `PD` (с `author_died` или `folk: true`), `own`, `CC0`, `CC BY 4.0`, `CC BY-SA 4.0`, `CC BY-NC 4.0`. Всё остальное `refpipe` не пропустит.

**3.4. Вырезать фрагмент** 20–40 с (секунды — по минусу). До первой ноты нужно ≥2,5 с тишины, после последней ≥1,5 с — `cut` сам оставит только целые фразы между `--t0` и `--t1`:
```
uv run refpipe cut ../songs-src/kalinka/song.txt --t0 0 --t1 34 --out ../songs/kalinka --minus ../songs-src/kalinka/minus.wav --guide ../songs-src/kalinka/guide.wav
```
- `--t0` никогда не бывает отрицательным. Если первая фраза начинается раньше 2,5 с, добавь в MuseScore вступление (например 2 пустых такта) и заново экспортируй `melody.mid` и `minus.wav`.
- Фразы, которые не влезли целиком, `cut` выбрасывает и пишет `warning: phrase N (… s) dropped` — проверь, что потерялось не то, что нужно.
- Если guide записан не от начала минуса, добавь `--guide-offset-ms N` (N > 0, когда голос в `guide.wav` звучит позже, чем в минусе).

**3.5. Собрать эталон**
```
uv run refpipe compile ../songs/kalinka
```

**3.6. Послушать, совпадает ли**
```
uv run refpipe preview ../songs/kalinka
```
Открой `data/preview/kalinka.wav` (в корне репо): поверх минуса пищит синус — это ноты эталона. Писк должен идти **ровно** с мелодией. Если спешит или опаздывает — подбери сдвиг в миллисекундах:
```
uv run refpipe preview ../songs/kalinka --shift-ms -20
```
(только послушать), а когда совпало — тот же сдвиг с `--apply`, он запишется в песню. После `--apply` повтори шаг 3.7: старый `check.json` помечается устаревшим и прячет песню до новой проверки.

**3.7. Проверка**
```
uv run refpipe check ../songs/kalinka
```
Должно быть `PASS`. Если `FAIL`:

| Код | Что значит | Что делать |
|---|---|---|
| `golden_share` | золотых меньше 5% или больше 15% | шаг 3.2, потом снова 3.4–3.7 |
| `lead_in` / `tail` | мало тишины до первой / после последней ноты | шаг 3.4 с другими `--t0` / `--t1`; после смены `--t0`/`--t1` повтори шаги 3.5–3.7 |
| `range` | диапазон шире 19 полутонов | взять другой фрагмент |
| `no_overlap` / `min_note_len` | ноты накладываются или короче 0,1 с | поправить MIDI и повторить с шага 3.1 |
| `guide_present` | нет `guide.mp3` | шаг 3.4 с `--guide` |
| `minus_present` | нет `minus.mp3` — песня не загрузится | шаг 3.4 с `--minus`, потом 3.5–3.7 |
| `fragment_len` / `note_count` (предупреждения) | фрагмент не 20–40 с или нот не 40–120 | поправить `--t0` / `--t1` |
| `score_guide`, `guide_pitch_class`, `guide_onset` | голос не совпадает с нотами | перепроверь MIDI, сдвиг из шага 3.6 или перепой guide |
| `score_guide` / `guide_pitch_class` падают, а preview звучит ровно | guide сдвинут относительно минуса | переэкспортируй выровненный голос или задай `--guide-offset-ms` в шаге 3.4; эталон через `preview --apply` ради guide не двигать |
| `guide_lag` (предупреждение) | guide сдвинут относительно эталона на столько мс | если preview звучит ровно — это сдвиг guide: `--guide-offset-ms` с этим числом в шаге 3.4 |
| `reference_fresh` (предупреждение) | `reference.json` не совпадает с `song.txt` + `meta.yaml` | повтори шаги 3.5–3.7 |
| `meta_matches_txt` (предупреждение) | `#TITLE`/`#ARTIST` в `song.txt` не равны `title`/`artist` в `meta.yaml` | шаг 3.3 |
| `word_breaks` (предупреждение) | в длинной строке нет пробелов — слова склеились | шаг 3.2, верни пробелы после слогов |
| `media_size`, `guide_onset_found` (предупреждения) | mp3 больше 1 МБ / у многих нот guide не нашлось начала | укороти фрагмент / перепроверь guide |

Песня с `FAIL` в игре **не появится** — бэкенд её прячет.

**3.8. Титры**
```
uv run refpipe credits
```
Обновит `CREDITS.md` в корне.

**3.9. Спеть в игре**
```
cd .. && make backend
```
Открой http://localhost:8000/dev.html → выбери песню → «Загрузить» → «Старт» → спой. Ноты на дорожке должны идти вместе с мелодией.

### 4. Залить
В git:
- `songs/kalinka/` — `song.txt`, `reference.json`, `minus.mp3`, `guide.mp3`, `meta.yaml`, `check.json` (mp3 ≤1 МБ каждый);
- `CREDITS.md`;
- строка песни в `docs/70 Песни/Реестр песен и лицензий.md` (колонки «Вокал», «Эталон», «check»).

НЕ в git: `songs-src/`, `data/`.


## Если хочется другую песню
Только PD (автор умер больше 70 лет назад, или народная) или под свободной лицензией (CC0, CC BY, CC BY-SA, CC BY-NC) — со своей аранжировкой и своим голосом. Оригиналы и минусовки популярных песен из интернета не берём: их нельзя в публичное репо. Если очень нужна конкретная песня — сначала напиши Паше, это решается отдельно.

## Раскладка папки песни
`songs/<id>/` = `song.txt reference.json minus.mp3 guide.mp3 meta.yaml check.json` (+ необязательный `cover.jpg`). `<id>` — только строчная латиница, цифры, `_` и `-`, иначе `compile` откажет. `songs/demo` — синтетическая песня для разработки (wav, без `meta.yaml` и `check.json`), раскладку с неё не копировать. mp3 44,1 кГц, `-q:a 2`, ≤1 МБ. Исходники и стемы — вне репо (`songs-src/`). Лицензии — `docs/70 Песни/Реестр песен и лицензий.md`.
