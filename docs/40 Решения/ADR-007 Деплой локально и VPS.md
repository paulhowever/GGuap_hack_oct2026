# ADR-007 Деплой локально и VPS

**Статус:** принято · **Дата:** 2026-10-08 · **Решили:** команда

## Контекст
Площадка: сеть и HTTPS непредсказуемы; localhost — secure context для микрофона.

## Решение
Демо на защите — локально на маке Паши (`http://localhost:8000`), плюс онлайн-версия на VPS за Caddy с HTTPS.

## Альтернативы
Только онлайн; только локально.

## Последствия
CUDA-сервер в игровом рантайме не участвует, только офлайн-пайплайн эталонов.
