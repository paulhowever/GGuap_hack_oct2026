# ADR-005 Формат эталонов UltraStar

**Статус:** принято · **Дата:** 2026-10-08 · **Решили:** команда

## Контекст
Стандарт всех клонов SingStar; его выдаёт UltraSinger; есть парсеры и редакторы.

## Решение
Эталоны храним в UltraStar TXT, бэкенд компилирует их в `reference.json`.

## Альтернативы
Свой формат с нуля; MIDI.

## Последствия
Отклоняем RELATIVE и дуэтные P1/P2. Конвертер `refpipe compile`.
