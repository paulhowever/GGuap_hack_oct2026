# ADR-008 Дуэли по ссылке

**Статус:** принято · **Дата:** 2026-10-08 · **Решили:** команда

## Контекст
Почти бесплатно поверх лидерборда, виральная механика для питча «Звуку».

## Решение
Дуэль — асинхронный вызов по ссылке `/c/{id}` и QR.

## Альтернативы
Хотсит; реалтайм на двух устройствах (комнаты, WebSocket, синхронизация).

## Последствия
Без аккаунтов: ник + clientId. Сложность фиксируется вызовом.
