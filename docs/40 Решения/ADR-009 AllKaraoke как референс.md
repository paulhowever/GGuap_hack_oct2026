# ADR-009 AllKaraoke как референс

**Статус:** принято · **Дата:** 2026-10-08 · **Решили:** команда

## Контекст
Форк выглядел бы перекраской чужого проекта и не задействовал Godot.

## Решение
AllKaraoke (MIT) читаем как референс, код в продукт не форкаем.

## Альтернативы
Форк целиком.

## Последствия
Клон лежит в `refs/` (локально, git-excluded). Берём идеи: правила очков, input lag, формат.
