# Решения (ADR)

Каждое значимое решение — отдельная заметка по шаблону [[ADR]]. Переигрываем только новой ADR со ссылкой на старую.

- [[ADR-001 Godot web и JS-мост]] — Фронт — Godot 4 web export, связь с аудио через JavaScriptBridge (вариант A).
- [[ADR-002 Всё аудио в JS]] — Минус, микрофон, живой питч и запись дубля живут в `voice.js` на одном AudioContext. Godot не играет минус.
- [[ADR-003 Живой питч pitchy]] — Живой питч — pitchy (MIT, McLeod) в AudioWorklet.
- [[ADR-004 Финальная оценка на бэкенде]] — Дубль (WAV 16 кГц) уходит на FastAPI; f0 считает SwiftF0 на CPU или torchcrepe на CUDA; оценка по нотам в стиле UltraStar + объяснение по строкам.
- [[ADR-005 Формат эталонов UltraStar]] — Эталоны храним в UltraStar TXT, бэкенд компилирует их в `reference.json`.
- [[ADR-006 Демо-песни народные PD]] — Демо-фрагменты — народные мелодии в общественном достоянии со своей аранжировкой и своим вокалом; UltraSinger — для импорта «любой трек».
- [[ADR-007 Деплой локально и VPS]] — Демо на защите — локально на маке Паши (`http://localhost:8000`), плюс онлайн-версия на VPS за Caddy с HTTPS.
- [[ADR-008 Дуэли по ссылке]] — Дуэль — асинхронный вызов по ссылке `/c/{id}` и QR.
- [[ADR-009 AllKaraoke как референс]] — AllKaraoke (MIT) читаем как референс, код в продукт не форкаем.
- [[ADR-010 Godot MCP]] — Для работы Claude Code с Godot-проектом — Coding-Solo/godot-mcp, ставится локально из клона с зафиксированным коммитом.
- [[ADR-011 Документация в docs]] — Obsidian-волт живёт в `docs/` репозитория.
- [[ADR-012 Лицензия MIT]] — Репозиторий под MIT.
