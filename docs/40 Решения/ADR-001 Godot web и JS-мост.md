# ADR-001 Godot web и JS-мост

**Статус:** принято · **Дата:** 2026-10-08 · **Решили:** команда

## Контекст
Макс силён в Godot. Микрофон внутри Godot web ненадёжен (Sample-режим без эффектов, жалобы на запись в 4.5).

## Решение
Фронт — Godot 4 web export, связь с аудио через JavaScriptBridge (вариант A).

## Альтернативы
Всё в Godot (риск микрофона); стрим питча на бэкенд по WebSocket (задержка, сеть на площадке).

## Последствия
Мост — строки JSON через `window.voice`; Godot опрашивает `poll()` раз в кадр. Паша тестирует движок без Godot.
