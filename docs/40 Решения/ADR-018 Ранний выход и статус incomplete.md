# ADR-018 Ранний выход: статус incomplete, доля допетого и честный too_fast

**Статус:** принято · **Дата:** 2026-10-15 · **Решили:** Паша

## Контекст
Игрок может выйти из песни раньше конца. Честный ранний `stop()` присылал короткий WAV, а `too_fast` сравнивал время ожидания с длиной всей песни (`issued_at + duration − 2 с`), поэтому такой дубль получал `suspect`. Это неверно: игрок ничего не нарушал. Исследование референсов: UltraStar сохраняет очки, только если песню допели до конца; AllKaraoke показывает частичный счёт с процентом пройденного.

## Решение
- **`too_fast` по записанной длине.** Конец записи `covered_end = wav_t0 + samples/sr` (song-time последнего сэмпла), `covered = max(0, min(duration, covered_end))`; флаг, если `now() < issued_at + covered − 2 с`. Длинный WAV, присланный слишком рано, по-прежнему `too_fast`; честный ранний выход — нет.
- **Новый флаг `incomplete`:** `covered_end < last_end − 0,5 с`, где `last_end` — `stats.last_end` эталона (если нет — максимум `t + d` по нотам).
- **Новый статус `incomplete`.** В `integrity.py` множество `SUSPECT` задано явно: `bad_session`, `too_fast`, `duplicate`, `replay`, `not_voice`; `incomplete` и `no_session` в него не входят. Приоритет: `suspect` > `incomplete` > `unverified` > `ok`.
- **`completion {ratio}` в `result.json`** сразу после `integrity`: `ratio = round(clamp((covered_end − first_note) / (last_end − first_note), 0, 1), 2)`, `first_note` — `stats.first_note` (если нет — минимальное `t`); если `last_end ≤ first_note`, то `1.0`.
- **Дубль оценивается как обычно:** непропетые ноты — промахи, дубль сохраняется, `POST /takes` и `GET /takes/{id}` отдают один и тот же результат.
- **Лидерборд и `top` — только `ok`.** `incomplete` туда не попадает, `leaderboard` в ответе `null`.
- **Соперники дуэли — только `ok`.** `GET /challenges/{id}` перечисляет лишь тех, чей дубль `ok`; блок `challenge` в ответе самому участнику не меняется, он видит своё сравнение.

## Альтернативы
- Без раннего выхода: дубль не отправляется, кнопки «Выйти» нет — игрок теряет запись и объяснение по спетым строкам.
- Пауза через `AudioContext.suspend` — отложена (P1), отдельная задача.
- Частичные дубли в лидерборде — нечестно к тем, кто допел; разные длины несравнимы.

## Последствия
- Godot: кнопка «Выйти» с подтверждением «результат не попадёт в рейтинг»; на экране результата — «допето N%» из `completion.ratio`. Godot обязан переживать новый статус `incomplete`.
- Пауза — отдельная задача позже.
- Соперник с дублем не `ok` не виден другим в списке вызова, хотя сам видит сравнение.
