# ADR-004 Финальная оценка на бэкенде

**Статус:** принято · **Дата:** 2026-10-08 · **Решили:** команда

## Контекст
Требование кейса — объяснение оценки; нейросеть на бэкенде даёт точность и техническую историю для жюри.

## Решение
Дубль (WAV 16 кГц) уходит на FastAPI; f0 считает SwiftF0 на CPU или torchcrepe на CUDA; оценка по нотам в стиле UltraStar + объяснение по строкам.

## Альтернативы
Только клиентская оценка; DTW по кривым (stretch).

## Последствия
Живой счёт в игре помечается «≈», финальный приходит за ≤3 с. Баланс в `contracts/scoring.json`.
