# ADR-006 Демо-песни народные PD

**Статус:** принято · **Дата:** 2026-10-08 · **Решили:** команда

## Контекст
Юридически чисто, эталон из MIDI точный, можно измерить точность UltraSinger (note-F1) для питча.

## Решение
Демо-фрагменты — народные мелодии в общественном достоянии со своей аранжировкой и своим вокалом; UltraSinger — для импорта «любой трек».

## Альтернативы
CC-треки с вокалом; смешанный вариант.

## Последствия
Критический путь по времени: минусы и запись вокала начинать 8–10.10. Только CC BY / BY-SA / CC0 для импорта.
