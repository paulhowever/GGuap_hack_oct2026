# ADR-010 Godot MCP

**Статус:** принято · **Дата:** 2026-10-08 · **Решили:** команда

## Контекст
Файловый/CLI-сервер, не требует `addons/` в репо.

## Решение
Для работы Claude Code с Godot-проектом — Coding-Solo/godot-mcp, ставится локально из клона с зафиксированным коммитом.

## Альтернативы
GDAI MCP (плагин в addons/), bradypp, GodotLens.

## Последствия
Конфиг MCP только локальный (`claude mcp add -s local`). Ошибки web-сборки ловим в браузере.
