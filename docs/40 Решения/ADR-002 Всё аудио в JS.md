# ADR-002 Всё аудио в JS

**Статус:** принято · **Дата:** 2026-10-08 · **Решили:** команда

## Контекст
Два аудиоконтекста (Godot и JS) дают дрейф часов и портят оценку ритма.

## Решение
Минус, микрофон, живой питч и запись дубля живут в `voice.js` на одном AudioContext. Godot не играет минус.

## Альтернативы
Минус через Godot.

## Последствия
Godot берёт `t_now` у JS. Звуки интерфейса во время пения не играем.
