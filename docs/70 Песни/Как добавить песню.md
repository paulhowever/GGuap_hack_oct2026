# Как добавить песню

Ветка `senya/songs`. Задача: к вечеру 16.10 в игре есть **Калинка** (обязательно) и **Коробейники** (если успеешь) — фрагмент 20–40 с, 40–120 нот. Готово — пушишь ветку и пишешь Паше, он проверяет.

Если у тебя есть Claude Code: открой репо в ветке `senya/songs`, дай ему этот файл и скажи «сделай песню kalinka по этой инструкции».

## 1. Подготовить исходники (не в git)
Папка `songs-src/<id>/` в корне репо, она в `.gitignore`. `<id>` — латиницей: `kalinka`, `korobeiniki`.

| Файл | Что | Как |
|---|---|---|
| `melody.mid` | только мелодия голоса, одна дорожка | MuseScore: набрать мелодию → File → Export → MIDI |
| `lyrics.txt` | текст по фразам | одна строка = одна фраза; слоги через дефис: `Ка-лин-ка, ка-лин-ка, ка-лин-ка мо-я`; один слог = одна нота; слог тянется на 2 ноты — допиши `~` (`мо-я-~`) |
| `minus.wav` | своя аранжировка без мелодии | в MuseScore добавить аккорды/бас/ударные, выключить партию мелодии, File → Export → Audio |
| `guide.wav` | голос | спеть мелодию под minus.wav в наушниках, с самого начала минуса; телефон подойдёт |

Важно: `melody.mid` и `minus.wav` начинаются в одну и ту же секунду (экспорт из одного файла MuseScore). Кто пел guide — даёт письменное согласие (сообщение в чате подойдёт).

Чужие записи и минусы (оригинал песни, минусовка из интернета) — не берём: их нельзя в публичное репо. Если хочется именно такую песню, напиши Паше до начала работы.

## 2. Один раз: окружение
```
cd ~/huap_hack_oct2026 && git switch senya/songs && make setup
brew install ffmpeg
```

## 3. Собрать песню
Все команды — из `~/huap_hack_oct2026/pipeline`. Пример для `kalinka`.

1. **Ноты + текст → song.txt**
   ```
   uv run refpipe from-midi ../songs-src/kalinka/melody.mid ../songs-src/kalinka/lyrics.txt -o ../songs-src/kalinka/song.txt --title "Калинка" --artist "нар. (И. Ларионов), аранж. huap team"
   ```
   - «lyrics have N syllables, melody has M notes» → поправь слоги в `lyrics.txt` (или `~`).
   - «rounds onto the same beat» → добавь `--bpm` с большим числом (например, удвоенный темп).
2. **Золотые ноты.** В `songs-src/kalinka/song.txt` поменяй `:` на `*` в начале 5–15% строк-нот (длинные ноты, кульминация).
3. **meta.yaml.** Скопируй `pipeline/examples/meta.example.yaml` в `songs/kalinka/meta.yaml` и поправь: `voice` (`male`/`female` — кто будет петь), `recording.title`, `vocalists` (имя, `consent: true`, дата), `changes` (какой фрагмент взят).
4. **Вырезать фрагмент** 20–40 с по целым фразам (секунды по минусу; до первой ноты нужно ≥2,5 с, после последней ≥1,5 с — `cut` сам выберет целые фразы внутри):
   ```
   uv run refpipe cut ../songs-src/kalinka/song.txt --t0 0 --t1 34 --out ../songs/kalinka --minus ../songs-src/kalinka/minus.wav --guide ../songs-src/kalinka/guide.wav
   ```
5. **Эталон:** `uv run refpipe compile ../songs/kalinka`
6. **Послушать:** `uv run refpipe preview ../songs/kalinka` → `data/preview/kalinka.wav`. Писк синуса должен совпадать с мелодией. Спешит или опаздывает — подбери сдвиг: `--shift-ms -20` (только послушать), потом тот же сдвиг с `--apply`.
7. **Проверка:** `uv run refpipe check ../songs/kalinka` → `check.json`, итог должен быть `PASS`. Частые FAIL:
   - `golden_share` — золотых нот меньше 5% или больше 15% (шаг 2);
   - `lead_in` / `tail` — мало тишины до первой или после последней ноты (шаг 4, сдвинь `--t0`/`--t1`);
   - `score_guide`, `guide_pitch_class`, `guide_onset` — голос не совпадает с нотами: перепроверь MIDI, сдвиг из шага 6 или перепой guide.
8. **Титры:** `uv run refpipe credits` (обновит `CREDITS.md`).
9. **В игре:** `cd .. && make backend`, открыть http://localhost:8000/dev.html, выбрать песню, «Загрузить» → «Старт», спеть.

## 4. Залить
- В git: `songs/<id>/` (`song.txt`, `reference.json`, `minus.mp3`, `guide.mp3`, `meta.yaml`, `check.json`), `CREDITS.md`, строка песни в [[Реестр песен и лицензий]] (колонки «Вокал», «Эталон», «check»).
- Не в git: `songs-src/`, `data/`.
- Коммит в `senya/songs`, `git push -u origin senya/songs`, написать Паше «готово».
