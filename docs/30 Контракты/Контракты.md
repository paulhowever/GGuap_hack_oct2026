# Контракты

Сквозные соглашения:
- Время в JSON задаётся в секундах song-time (0 соответствует началу minus.mp3) с 3 знаками после запятой.
- Задержки передаются в мс, у таких полей суффикс `_ms`.
- Основное поле высоты — `pc`. `midi` используется только для отрисовки.
- Типы нот: `normal|golden|free|rap|rap_golden`.

## 3.1 Мост `window.voice`
Одинаков в voice.js и voice.mock.js.

| Вызов Godot→JS | Результат |
|---|---|
| `subscribe(cb)` | `cb(name:string, json:string)` для всех событий |
| `unlock()` | Только из DOM-клика по оверлею. Создаёт ctx, делает resume, вызывает getUserMedia, addModule, регистрирует worklet и 1 с меряет шум. Godot получает `on_unlocked` |
| `configure(json)` | `{difficulty, lag_ms, music_volume, aec}` |
| `load_song(id)` | GET /api/songs/{id} и decode минуса. Затем `on_ready` |
| `start()` / `stop()` | Минус и запись. `stop` готовит WAV |
| `poll(): string` | См. ниже. Очередь кадров ≤ 2000 |
| `submit(player, challenge_id)` | POST /takes с таймаутом 10 с. Затем `on_result` или `on_error` |
| `calibrate()` | Даёт `on_calibrated` |

События JS→Godot: `on_unlocked{sr,noise_db,lag_ms,bt_suspect}`, `on_ready{reference…, scoring:{tol_cents}, lag_ms}`, `on_song_end{t}`, `on_result{result.json}`, `on_calibrated{lag_ms,hits}`, `on_error{code,msg}`.

Коды ошибок:
- `insecure_context|mic_denied|mic_not_found|audio_locked|worklet_failed|decode_failed|net|upload_failed`.

poll:
```json
{"t_now":12.345,"state":"idle|playing|ended","level":0.041,
 "frames":[{"t":12.301,"hz":261.6,"conf":1,"rms":0.042},{"t":12.312,"hz":0,"conf":0,"rms":0.004}]}
```
Отсчёт 3-2-1 Godot рисует сам, пока `t_now < stats.first_note`. Перед первой нотой в файле не меньше 2,5 с, поэтому offset не нужен.

## 3.2 reference.json (schema 1)
```json
{"schema":1,"id":"kalinka","title":"Калинка","artist":"нар. (И. Ларионов), аранж. команды","language":"ru",
 "audio":{"minus":"/media/kalinka/minus.mp3","guide":"/media/kalinka/guide.mp3","duration":31.0,"offset_ms":0},
 "timing":{"bpm_txt":300.0,"gap_ms":2500,"beat_s":0.05},
 "stats":{"notes":58,"lines":6,"range_midi":[57,74],"difficulty":2,"first_note":2.5,"last_end":29.1,"golden_share":0.09},
 "lines":[{"i":0,"t0":2.5,"t1":5.2,"text":"Калинка, калинка, калинка моя!","notes":[
   {"i":0,"t":2.5,"d":0.3,"beat":0,"len":6,"midi":69,"pc":9,"type":"normal","syl":"Ка"},
   {"i":2,"t":3.1,"d":0.6,"beat":12,"len":12,"midi":65,"pc":5,"type":"golden","syl":"ка, "}]}],
 "source":{"origin":"own_midi|ultrasinger|manual","generator":"UltraSinger x.y","t0_ms":61200},
 "license":{"music":"PD","recording":"CC BY 4.0","attribution":"…","url":null}}
```
Как заполняется:
- Индекс ноты `i` сквозной.
- `t = gap_ms/1000 + beat*beat_s`, где `beat_s = 15/BPM`.
- `midi = pitch + 60`, октава выравнивается по диапазону голоса.
- Весов в файле нет, они берутся из scoring.json.

## 3.3 POST /api/takes
Multipart:
- `audio=take.wav`: mono int16 16 кГц, фолбэк — родная частота;
- `meta`:
```json
{"song_id":"kalinka","player":"Паша","difficulty":"normal","challenge_id":null,
 "wav_t0":-0.153,"wav_sr":16000,"lag_ms":48,"frames":[…],
 "client":{"ua":"…","sr":48000,"base_latency":0.005,"output_latency":0.012,"aec":false}}
```
`wav_t0` — song-time первого сэмпла без вычета задержки. Бэкенд считает `t_sung = wav_t0 + i/sr − applied_ms/1000`.

## 3.5 REST
Все пути начинаются с `/api`.

| Метод | Ответ |
|---|---|
| GET /songs | `[{id,title,artist,duration,difficulty,range_midi,license:{short,attribution},top:{player,total}}]`, только `check.pass` и `status:ready` |
| GET /songs/{id} | reference.json + `status: processing\|ready\|failed` |
| POST /takes | result.json, 200, ≤3 с. 413 при >60 с, 422 при неверном meta |
| GET /takes/{id} | result.json |
| GET /leaderboard/{song_id}?difficulty=normal&limit=20 | `{items:[{rank,player,total,grade,take_id,at}]}`, лучший `source=final` на ник |
| POST /challenges `{take_id}` | `{id:"ab12cd",url:"https://host/c/ab12cd"}` |
| GET /challenges/{id} | `{id,song_id,difficulty,owner:{player,total,take_id},rivals:[{player,total,take_id,verdict}]}` |
| POST /songs/import (multipart audio + `{title,artist,license_url,license}`) | 202 `{id}`. На сервере без `PIPELINE_SSH` отдаёт 503 |
| GET /c/{id} | 302 на `/?challenge={id}` |

## 3.6 songs/<id>/
```
song.txt  reference.json  minus.mp3  guide.mp3  vocals_f0.json  cover.jpg  meta.yaml  check.json
```
- mp3: 44,1 кГц, `-q:a 2`, не больше 1 МБ на файл, поэтому LFS не нужен.
- Исходники (полные треки, stems) лежат вне репо, на CUDA-сервере или диске.
