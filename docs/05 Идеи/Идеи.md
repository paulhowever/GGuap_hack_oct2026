# Идеи

Сюда кидает идеи вся команда. Одна идея — одна заметка из шаблона [[Идея]] в этой папке. Раз в день (на синке) разбираем: **берём** → задача в GitHub Issues или ADR, **позже** → тег `#stretch`, **нет** → статус `rejected` с причиной.
