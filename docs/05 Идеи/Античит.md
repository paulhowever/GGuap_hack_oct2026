# Античит

## Что
Не дать получить высокий балл без честного пения. Кандидаты (берём все, потом выбираем по результатам [[Красная команда — античит]]):
1. **Фонограмма** — запись коррелирует с оригинальным вокалом (guide): трек включили с телефона.
2. **Синт, свист, инструмент** — слишком ровный тон без естественного дрожания и без гармоник голоса.
3. **Мычание вместо слов** — Whisper на CUDA проверяет, что спеты слова текста.
4. **Подделка запроса** — сервер сам считает оценку по WAV, токен дубля с длительностью, подозрительное не идёт в лидерборд.

## Зачем
Честный лидерборд и дуэли, сильная техническая история для жюри, эффектный момент в демо («Э, это фонограмма!» от продюсера).

## Сколько стоит
Отдельный поток Паши: исследование методов → прототипы → замеры на наборе атак Арсения → выбор.

## Решение на синке
14.10: в MVP — фонограмма, «не голос», токен сессии + sha256; Whisper — stretch ([[ADR-017 Объём MVP и решения после ревью]]).

## Реализация
Код — `backend/app/anticheat/`: `session.py` (подписанный токен сессии, `too_fast`), `replay.py` (флаг `replay`), `voice.py` (флаг `not_voice`), `signal.py` (сборка сигнальных проверок), `integrity.py` (статус дубля, полнота). Повтор дубля по sha256 — `backend/app/api/takes.py`. Пороги и замеры — [[Красная команда — античит]].

С 16.10 сигнальные проверки слушают только громкие кадры: кадр выпадает из `replay` и `not_voice`, если он тише 90-го перцентиля громкости озвученных кадров дубля больше чем на 15 дБ (`AUDIBLE_DB`, `backend/app/anticheat/signal.py`). Так минус из колонок в пропущенных строках, вступлении и проигрыше не делает честный дубль «фонограммой». На оценку порог не влияет.
