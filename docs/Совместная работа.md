# Совместная работа в волте

Волт — это папка `docs/` репозитория. Синхронизация через git: все видят одно и то же, история правок есть в GitHub.

## Подключиться (10 минут)
1. Получить доступ к репо `paulhowever/huap_hack_oct2026` (Паша добавляет в Collaborators).
2. Склонировать: `git clone https://github.com/paulhowever/huap_hack_oct2026.git` (или GitHub Desktop, если без терминала).
3. Obsidian → «Open folder as vault» → выбрать папку `docs` внутри репо.
4. Settings → Community plugins → включить → Browse → **Git** (автор Vinzent03) → Install → Enable.
5. Настройки плагина Git: «Pull on startup» — вкл; «Auto commit-and-sync interval» — 10 мин; «Commit message» — `docs: {{date}} {{numFiles}} files`.
6. Settings → Core plugins → Templates: папка шаблонов `90 Шаблоны`.
7. По желанию: плагин **Dataview** — для таблицы на странице [[Идеи]].

## Правила, чтобы не ловить конфликты
- Одна заметка — один владелец (поле `owner` или см. [[Команда]]). В чужую заметку — комментарий в конце с `> [!note] Имя:` или новая заметка в [[Идеи]].
- Перед большой правкой — Pull (Cmd+P → «Git: Pull»), после — Commit-and-sync.
- Контракты ([[Контракты]]) и ADR меняются только через PR после FREEZE-1 (9.10).
- Картинки и скриншоты — в `99 Вложения/`, до 1 МБ.
