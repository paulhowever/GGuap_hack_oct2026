# Риски

1. **Эталоны не успеют** (свои минусы и вокал — критический путь). Митигации: начать 8.10, минимум 2 песни к 11.10, «Калинка» первой.
2. **Минус в микрофоне на площадке.** Митигации: наушники, сплиттер, динамический микрофон, флаг AEC, тест 17.10.
3. **Неверная задержка (HDMI, BT).** Митигации: калибровка на финальной цепочке, автокомпенсация ±120 мс, `bt_suspect`.
4. **pitchy не импортируется в AudioWorklet (бандл/Safari).** Митигации: тот же код в Worker через MessagePort, тест в первый день.
5. **Сюрпризы Godot web:** GC колбэков, шаблоны 4.7.2, thread_support, IME для русского ника. Митигации: колбэк хранится в поле, ранний web-экспорт 9.10, ник через HTML-поле в оверлее.
6. **Шок от разницы живого и финального счёта.** Митигации: живой показываем с «≈», анимация «судья слушает», лог |Δ| > 15%.
7. **Пороги не откалиброваны** (мычание даёт C, нормальное пение D). Митигации: golden-набор Сени, плейтест 15.10, coverage в ритме.
8. **Лицензии:** NC/ND, чужая аранжировка, лицензии моделей. Митигации: репо MIT, только свои аранжировки, реестр песен, проверка лицензии swift-f0.
9. **Сеть и HTTPS на площадке.** Митигации: всё на localhost, VPS только для QR, видео дуэли.
10. **Расползание объёма** (импорт, дуэли, stretch). Митигации: фризы, go/no-go 15.10, импорт показываем видео при сбое.
