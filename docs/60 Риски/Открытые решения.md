# Открытые решения

| Вопрос | Рекомендация |
|---|---|
| Лицензия репо | MIT. aubio заменён на pitchy (ADR-003), GPL-вопрос снят. Проверить лицензию swift-f0 |
| Допуски | easy 200 / normal 120 / hard 60 центов. По умолчанию normal. Плейтест 15.10 |
| Живой счёт | Число с «≈» мелко, крупно — индикатор попадания |
| Множитель F | 0, как в UltraStar |
| Повторы | Без лимита, в лидерборд идёт лучший результат на ник+сложность. Счётчик попыток только для UI |
| Наушники | Обязательны для певца. RMVPE и шумоподавление в stretch |
| Дорожка | Постранично по строкам. Скролл — stretch |
| challenge_id в Godot | `VoiceBridge.url_param("challenge")`, `/c/{id}` → 302 |
| Сложность в дуэли | Фиксируется вызовом |
| Длина фрагмента | 20–40 с, жёсткий максимум 60 с |
| Шкала | 10000, веса 0,65/0,25/0,10 |
| QR для зала | Только если мобильный Chrome/Safari пройдёт тест 15.10 |
| Регламент защиты | Узнать у организаторов, тайминг выше под 6:30 |
