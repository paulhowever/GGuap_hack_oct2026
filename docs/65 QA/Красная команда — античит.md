# Красная команда — античит

**Задача:** получить высокий балл, не спев честно. Каждая попытка — строка в таблице. Обман сработал — баг с меткой `anti-cheat`. Результаты решают, какие проверки войдут в демо ([[Античит]]).

## Сценарии атак
| ID | Атака | Как |
|---|---|---|
| A1 | Фонограмма | включить оригинал песни с вокалом с телефона у микрофона |
| A2 | Эталонный вокал | включить guide-вокал из игры |
| A3 | Инструмент | сыграть мелодию на онлайн-пианино или синте |
| A4 | Свист | просвистеть мелодию |
| A5 | Мычание | спеть мелодию без слов |
| A6 | Не те слова | «ла-ла-ла» в правильные ноты |
| A7 | Речь | проговорить текст, не петь |
| A8 | Минус из колонок | без наушников и без пения |
| A9 | Подделка запроса | для Паши: отправить чужой WAV или JSON через curl |
| A10 | Повтор | загрузить один и тот же дубль дважды |
