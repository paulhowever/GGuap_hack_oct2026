# Тест-кейсы

Приоритет: P1 — проверять каждую сборку, P2 — раз в день, P3 — перед защитой.

## Профиль
| ID | Шаги | Ожидаемо | P |
|---|---|---|---|
| TC-01 | Новый игрок: ник 1–24 символа, кириллица, эмодзи | ник сохраняется; пустой ник — нельзя продолжить | P1 |
| TC-02 | Повторный заход в том же браузере | ник и аватар восстановлены | P1 |
| TC-03 | Заход из другого браузера | новый игрок — это ожидаемо, без пароля | P3 |

## Микрофон и звук
| ID | Шаги | Ожидаемо | P |
|---|---|---|---|
| TC-10 | Нажать «Запретить» на запрос микрофона | понятное сообщение и как включить доступ | P1 |
| TC-11 | Ноутбук без микрофона или он отключён | сообщение «микрофон не найден» | P2 |
| TC-12 | Открыть игру с другого компьютера по `http://<IP>:8000` без флага Chrome | сообщение о небезопасном подключении; с флагом — микрофон работает | P2 |
| TC-13 | Подключить Bluetooth-наушники | предупреждение «нужны проводные» | P2 |
| TC-14 | Калибровка: хлопать под 8 щелчков | задержка 20–200 мс на проводных наушниках | P2 |
| TC-15 | Свернуть вкладку посреди песни | игра не зависает, после возврата можно начать заново | P2 |

## Оценка
| ID | Шаги | Ожидаемо | P |
|---|---|---|---|
| TC-20 | Спеть старательно и чисто | A и выше (≥ 7500) у того, кто умеет петь | P1 |
| TC-21 | Спеть на октаву ниже | оценка как на родной октаве + совет «на октаву ниже — не штрафуем» | P1 |
| TC-22 | Нарочно петь выше на полтона | мелодия падает, совет «выше на ~100 центов» | P1 |
| TC-23 | Начинать каждую строку с опозданием ~0,3 с | падает ритм, совет «опаздываешь» | P1 |
| TC-24 | Молчать всю песню | итог ≤ 200, совет «почти не слышно» | P1 |
| TC-25 | Спеть только первую половину | строки второй половины — Miss | P2 |
| TC-26 | Музыка в комнате, сам не поёшь | очков почти нет | P2 |
| TC-27 | Спеть одинаково два раза подряд | итоги отличаются не больше чем на 5% | P2 |

## Результат и объяснение
| ID | Шаги | Ожидаемо | P |
|---|---|---|---|
| TC-30 | Дождаться экрана результата | итог, грейд, три шкалы, график, строки, до трёх советов, строка «как считали» | P1 |
| TC-31 | Сверить советы с тем, что делал | советы совпадают с ощущениями | P1 |
| TC-32 | Сравнить живой «≈» счёт и финальный | разница не больше 15% | P2 |

|---|---|---|---|

| TC-51 | Два игрока с одинаковым ником в разных браузерах | оба видны в лидерборде, различаются аватарами | P3 |
