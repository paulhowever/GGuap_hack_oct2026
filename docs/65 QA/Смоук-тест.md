# Смоук-тест (5 минут)

Прогоняется после каждого обновления стенда. Упал любой шаг — баг «Блокер», дальше не тестируем.

- [ ] S1 Страница открылась за ≤10 с, в консоли (F12) нет красных ошибок
- [ ] S2 `?debug=1` показывает версию и git sha, совпадающие с последним коммитом в `main`
- [ ] S3 `/api/v1/health` отдаёт `"status": "ok"`
- [ ] S4 Ввёл ник, собрал аватара, перезагрузил страницу — ник и аватар на месте
- [ ] S5 Браузер спросил доступ к микрофону; после «Разрешить» индикатор уровня реагирует на голос
- [ ] S6 Выбрал песню: минус играет, ноты и текст идут синхронно
- [ ] S7 Спел строку: линия голоса появляется на дорожке, продюсер реагирует
- [ ] S8 После песни за ≤3 с экран результата: итог, три шкалы, разбор по строкам, советы
- [ ] S9 «Ещё раз» запускает новую попытку, лидерборд показывает лучший результат
- [ ] S10 `?mock=perfect` даёт итог ≥ 9000 и восторг продюсера
