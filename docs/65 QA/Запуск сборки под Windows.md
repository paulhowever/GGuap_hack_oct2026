# Запуск сборки под Windows (без редактора Godot)

Игра работает в браузере. Её раздаёт бэкенд: `http://localhost:8000/` → папка `dist/web`.
Редактор Godot для запуска не нужен. Для **сборки** нужен только `Godot.exe` (он запускается без окна, в headless-режиме).

## Что нужно один раз

| Что | Зачем | Проверка |
|---|---|---|
| `uv` | запуск бэкенда | `uv --version` |
| Godot 4.8-dev7 (`Godot_v4.8-dev7_win64.exe`) | экспорт игры | путь к exe |
| Шаблоны экспорта Web для этой версии | экспорт игры | Godot → Editor → Manage Export Templates |
| Chrome или Edge | игра + микрофон | — |

Скрипт сборки ищет Godot сам, в таком порядке:
1. параметр `-Godot "C:\путь\Godot.exe"`;
2. переменная `$env:GODOT`;
3. `godotTools.editorPath.godot4` в `.vscode/settings.json`;
4. `godot*` в `PATH`.

## 1. Собрать `dist/web`

PowerShell из корня репозитория:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build-web.ps1
```

- Занимает около минуты. В конце должно быть `== Готово: dist/web собран полностью`.
- Менялся только `web/` (voice.js и т. п.)? Добавьте `-SkipExport`: Godot пропускается, только копирование.
- Сборку повторяем после любых изменений в `godot/` или `web/`. Бэкенд при этом перезапускать не нужно, достаточно обновить страницу (Ctrl+F5).

Готовая папка `dist/web` — это вся игра: `index.html/js/wasm/pck` от Godot + `config.js`, `voice.js`, `vendor/pitchy.bundle.js` из `web/`.

## 2. Запустить бэкенд

Отдельное окно PowerShell, не закрывать во время игры:

```powershell
cd backend
uv sync          # только в первый раз
uv run uvicorn app.main:app --port 8000
```

Ждём `Uvicorn running on http://127.0.0.1:8000`.
По умолчанию бэкенд раздаёт `dist/web` (`web_dir` в `backend/app/core/config.py`), другую папку можно задать через `KARAOKE_WEB_DIR`.

## 3. Открыть игру

| Адрес | Что |
|---|---|
| `http://localhost:8000/?mock=perfect` | без микрофона, идеальное пение (итог ≥ 9000) |
| `http://localhost:8000/?mock=offkey` | без микрофона, фальшиво |
| `http://localhost:8000/?mock=silent` | без микрофона, тишина |
| `http://localhost:8000/` | живой микрофон (браузер спросит доступ; лучше в наушниках) |

Микрофон работает только на `localhost` или по HTTPS: открывать файл `index.html` двойным щелчком нельзя.

## Если не работает

| Симптом | Причина | Что делать |
|---|---|---|
| `{"detail":"Not Found"}` на `/` | нет `dist/web/index.html` | запустить шаг 1; проверить, что бэкенд запущен из `backend/` с актуальным кодом |
| `-ExecutionPolicy не распознано` | команда вставлена без `powershell` в начале | вставить строку целиком |
| `Godot не найден` | скрипт не нашёл exe | `-Godot "C:\...\Godot_v4.8-dev7_win64.exe"` |
| `После экспорта нет dist/web/index.pck` | нет шаблонов экспорта Web | установить шаблоны для 4.8-dev7 |
| `В dist/web нет: vendor\pitchy.bundle.js` | не собран вендор | `cd web; npm install; npm run vendor`, затем шаг 1 с `-SkipExport` |
| Игра идёт, но без голоса, в консоли «voice.js не найден» | страница открыта не через бэкенд (например, «Run in Browser» из редактора) | открывать только `http://localhost:8000/` |
| Порт 8000 занят | старый бэкенд не закрыт | закрыть его окно или `--port 8001` и тот же порт в адресе |

При баге присылайте: шаг, красные строки из консоли браузера (F12 → Console), последние строки окна бэкенда.
