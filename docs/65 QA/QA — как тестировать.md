# QA — как тестировать

Главное правило: **Арсений ничего не собирает и не запускает в терминале.** Всё тестируется по ссылке в браузере, баги — формой в GitHub Issues, методика — в этой папке.

## Где тестировать
| Что | Адрес | Когда обновляется |
|---|---|---|
| Мак Паши по Wi-Fi | `http://<IP мака>:8000` — Паша пишет IP в чат | когда Паша запустил свежую сборку |
| Локально у Паши или Макса | `http://localhost:8000` | вручную |
| Звук без Godot | `/dev.html` | вместе с `voice.js` |
| Здоровье бэкенда | `/api/v1/health` | всегда |

## Как открыть игру с мака Паши
Сервера нет — игра крутится на маке Паши. По Wi-Fi браузер считает адрес небезопасным и не даёт микрофон, поэтому один раз:
1. Chrome → в адресной строке `chrome://flags/#unsafely-treat-insecure-origin-as-secure`.
2. В поле вписать `http://<IP мака>:8000` (IP Паша пишет в чат), переключатель — **Enabled**.
3. **Relaunch**. Теперь `http://<IP мака>:8000` работает с микрофоном.

Вы должны быть в одной сети. Если IP поменялся — повторить шаг 2 с новым.

## Режимы в адресной строке
| Параметр | Что делает | Зачем тебе |
|---|---|---|
| `?mock=perfect` / `offkey` / `octave` / `late200` / `silent` | вместо микрофона — заранее заданный «голос» | проверить экраны, продюсера и результат без пения |
| `?debug=1` | оверлей: версия и git sha, частота дискретизации, задержка, высота голоса в Гц | копировать в баг-репорт |
| `?challenge=<id>` | открыть дуэль по ссылке | дуэли |

## Цикл работы
1. На доске GitHub колонка **Ready for QA** — твоя очередь. Разработчик переносит туда задачу, когда закончил.
2. Открываешь игру (см. «Как открыть игру с мака Паши») и делаешь [[Смоук-тест]] (5 минут). Упал смоук — дальше не тестируешь, сразу баг «Блокер».
3. Проверяешь задачу по её критерию готовности и по [[Тест-кейсы]].
4. Всё ок — переносишь в **Done**. Не ок — баг через форму, задачу возвращаешь в **In progress** со ссылкой на баг.
5. В конце дня — заметка из шаблона [[Тест-сессия]] в `65 QA/Сессии/`.

## Как писать баг
Только через форму: GitHub → Issues → New issue → **Баг**. Форма сама спросит всё нужное:
- версию из `?debug=1` (или `/api/v1/version`);
- браузер, наушники и микрофон;
- шаги, что ожидал, что получил;
- видео экрана: QuickTime → Файл → Новая запись экрана. 10 секунд видео лучше абзаца текста;
- если что-то «молча не работает» — F12 → Console → скопировать красные строки.

Идея или «неудобно» — форма **Идея или UX-фидбек**.

## Окружение
- Chrome — основной, Safari — второй, остальное по остатку.
- Только проводные наушники. Bluetooth даёт задержку 150–300 мс — это не баг, но игра обязана об этом предупредить.
- Тихая комната — для [[Золотой набор дублей]]; шумная (коридор, кафе) — для проверки шума.

## Что ещё на тебе
- [[Золотой набор дублей]] — каждый день ~15 минут: поёшь и ставишь себе оценку. Это данные для настройки оценки и твоё «научиться петь за неделю».
- [[Красная команда — античит]] — пытаешься обмануть игру и записываешь, получилось ли.

## Что разработчики обязаны дать тестированию
| Что | Кто |
|---|---|
| Версия приложения видна в UI (`?debug=1`, футер) | Макс (UI) + Паша (`/api/v1/version`) |
| Режимы `?mock=…` с событиями для продюсера | Паша (`voice.mock.js`) |
| Свежая сборка запущена на маке и IP объявлен в чате | Паша |
| У каждой задачи в Issues — критерий готовности | все |
