# Золотой набор дублей

**Зачем:** настроить оценку по живым людям, а не по синусоидам ([[ADR-014 MLflow для экспериментов]]). Главная метрика — насколько балл игры совпадает с человеческой оценкой (корреляция Спирмена). Заодно это твоё «научиться петь за неделю».

**Кто поёт:** Арсений и все, кто готов. Каждый, чей голос записан, ставит «да» в колонке согласия.

## Как
1. Открыть игру с `?debug=1`, сложность **normal**.
2. Перед песней решить, *что* пробуешь: спеть хорошо, выше, ниже, на октаву ниже, с опозданием, мычать…
3. Спеть. **Сразу после песни, не глядя на результат** (отвернись от экрана), поставь себе оценку 1–5.
4. Записать строку в таблицу ниже: `take_id` есть в оверлее и на экране результата.

Цель к 16.10: 15 дублей на 3 песнях — треть хороших, треть средних, треть нарочно плохих.

## Что пробовал (метки)
`ok` · `sharp` (выше) · `flat` (ниже) · `octave` · `late` · `early` · `hum` (мычание) · `noise` (шум вокруг) · `silence`
