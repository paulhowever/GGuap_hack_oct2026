# Продукт и демо

**Экраны.**
1. **Boot.** Оверлей «Нажми, чтобы начать», ник, «нужны проводные наушники», калибровка за 5 с (можно пропустить).
2. **Select.** 3–4 карточки: ★ сложности, диапазон, длительность, топ-1, плашка лицензии; выбор easy, normal или hard.
3. **Sing.** Отсчёт, NoteLane, караоке-текст, PitchMeter, живой счёт «≈», golden-ноты мерцают.
4. **«Судья слушает…»** (1–3 с). Живой «≈» анимированно сменяется финальным счётом.
5. **Result.**
   - Итог 0–10000, грейд S–D.
   - Три шкалы: Мелодия (% нот в допуске, октава не важна), Ритм (% и средний сдвиг атаки в мс), Точность (perfect-ноты, golden x/y).
   - График «ты и эталон» с подсвеченной худшей строкой.
   - LineRow: текст, балл, тег.
   - До 3 советов.
   - Строка «как считали»: «задержка компенсирована на 168 мс · пересчёт нейросетью SwiftF0».
   - Атрибуция трека.
   - Кнопки «Ещё раз», «Вызвать друга», «Лидерборд».
6. **Leaderboard.** Топ-20, своя строка подсвечена.
7. **Duel.**
   - Ссылка `/c/ab12cd` открывает экран «Паша вызывает: 7420 на “Калинке” (normal)».
   - Кнопка «Принять» ведёт в Sing, затем экран сравнения: строки бок о бок с победителем каждой и итоговая разница.
   - Автор вызова видит исход по той же ссылке.

**Питч для «Звука».**
- Тезис «от слушания к участию».
- По нашему поиску, оценки пения и баттлов нет ни у «Звука», ни у Яндекс Музыки (sing along), ни у VK. Проверить перед защитой.
- Вызов по ссылке — канал виральности (K-фактор), повторы — удержание. Что поют пользователи — сигнал для рекомендаций и UGC.
- Импорт «любой трек → караоке» масштабирует каталог при наличии прав.

**Защита (6:30, если регламент другой — сжать техническую часть):**

| Время | Что |
|---|---|
| 0:00–0:40 | Хук: поёт член жюри |
| 0:40–2:30 | Живой проход, смена «≈» на финальный счёт, разбор строк |
| 2:30–3:15 | Дуэль по QR, второй певец, экран сравнения |
| 3:15–4:45 | Техника: схема, единые часы и автокомпенсация, двухступенчатая оценка, видео импорта 20 с, реестр лицензий, тестовые коридоры |
| 4:45–5:45 | Ценность и метрики |
| 5:45–6:30 | Roadmap, команда |

**Площадка: что сломается и как страхуемся.**
- **Минус из колонок попадает в микрофон.** Певец слушает минус в проводных наушниках. Зал слышит через сплиттер или USB-интерфейс с двумя выходами. Микрофон кардиоидный динамический у рта. Резерв — `configure({aec:true})`, на 17.10 проверить, что даёт лучший счёт.
- **HDMI/AirPlay на проектор.** Звук не выводим через HDMI, он добавляет непредсказуемую задержку. Калибруем `lag_ms` 17.10 на финальной цепочке и прописываем в config.js.
- **Bluetooth.** Запрещён. Предупреждение по `bt_suspect`.
- **Разрешения.** Отдельный профиль Chrome, микрофон для `localhost:8000` выдан заранее. Вход по умолчанию в macOS выставлен на нужный микрофон. Режим микрофона «Стандартный».
- **Шум.** noise floor меряется при unlock, rms-gate. Подсказка silence. Певец близко к микрофону.
- **HTTPS и сеть.** Демо на `http://localhost` (secure context), полностью офлайн. Онлайн-версия только для QR дуэли, при отсутствии сети показываем записанную дуэль.
- **Автоплей.** Только DOM-оверлей.
- **Сон и троттлинг.** `caffeinate -dims`, вкладка на переднем плане, экран не гаснет.

**План Б:**
1. Микрофон сбоит → `R` прогоняет записанный дубль через реальный API.
2. Бэкенд упал → Godot показывает живой счёт с бейджем «офлайн», без лидерборда.
3. Всё упало → видео 90 с (снять 16.10).
4. Вторая машина: ноутбук Макса с той же сборкой.
