# Эталоны и пайплайн

**UltraStar TXT.**
- UTF-8 (cp1251 определяется автоматически).
- Обязательные заголовки: TITLE, ARTIST, BPM, GAP, AUDIO/MP3. Десятичная запятая допустима.
- Отклоняем `RELATIVE`, P1/P2 и файлы без нот.
- Нота: `^([:*FRG]) (-?\d+) (\d+) (-?\d+) (.*)$`, фраза `- B`, конец `E`.
- `:`→normal, `*`→golden, `F`→free, `R`→rap, `G`→rap_golden.

**Основной путь (3 фрагмента).**
- Народные мелодии в общественном достоянии и своя аранжировка: «Калинка», «Во поле берёза стояла», «Коробейники» или «Ой, то не вечер».
- Минус делаем в MuseScore 4 или GarageBand по MIDI.
- Вокал записывают 2 голоса, мужской и женский, с письменным согласием.
- `refpipe from-midi melody.mid lyrics.txt → song.txt` даёт точный эталон.
- Тот же микс прогоняем через UltraSinger и считаем note-F1 (onset ±100 мс, pc ±1). Получается цифра для питча.

**CC-путь** (1 трек для импорта):
- только CC BY, CC BY-SA, CC0, без NC и ND;
- скриншот страницы с лицензией кладём в meta.yaml.

**UltraSinger на CUDA** (окружение поднять до 10.10):
```
python UltraSinger.py -i full.wav -o out --whisper large-v2 --language ru \
  --whisper_align_model jonatasgrosman/wav2vec2-large-xlsr-53-russian \
  --whisper_batch_size 16 --whisper_compute_type float16 --demucs htdemucs_ft \
  --format_version 1.1.0 --keep_cache [--disable_hyphenation]
```

**Резка.**
- Demucs гоняем на полном треке, режем потом.
- `ffmpeg -i no_vocals.wav -ss T0 -to T1 -af "afade=t=in:d=0.3,afade=t=out:st=D-1:d=1" -ar 44100 -c:a libmp3lame -q:a 2 minus.mp3`. Guide режем с теми же T0/T1.
- `refpipe cut --t0 --t1`: только целые фразы, `GAP' = GAP + b0·beat_ms − t0`. Перед первой нотой ≥2,5 с, после последней ≥1,5 с. Фрагмент 20–40 с, 40–120 нот.

**Проверка `refpipe check → check.json`:**
1. Структура: ноты не перекрываются, длина ≥100 мс, диапазон ≤19 полутонов, golden 5–15%.
2. Высота: pc f0 guide совпадает в пределах ±1 полутона у ≥90% нот.
3. Тайминг: медиана |onset| ≤ 80 мс.
4. Самооценка скорером: guide ≥ 90%, guide ±12 полутонов — столько же, guide +2 полутона ≤ 40%, тишина = 0, guide с задержкой +150 мс ≥ 85%.
5. `refpipe preview`: минус плюс синус на −12 дБ, прослушка, правка GAP шагом ±10 мс.
6. Ручная вычитка текста: 30–60 мин на фрагмент. Golden-ноты расставляет Сеня.

**Лицензии.**
- Блок TASL и список изменений в meta.yaml.
- Атрибуция показывается на карточке песни и на экране результата.
- CREDITS.md генерируется из всех meta.yaml.
- Автор песни должен быть мёртв больше 70 лет (+4 года за ВОВ).

**POST /songs/import** → фоновый `ssh $PIPELINE_SSH refpipe import` (UltraSinger → cut → compile → check) → `status`.
