# Архитектура и владение

```
Chrome (один origin: http://localhost:8000 | https://karaoke.<домен>)
┌──────────────────────────────────────────────────────────┐
│ shell.html (Саня) + HTML-оверлей «Нажми, чтобы начать»    │
│ ┌──────────── Godot 4.7.2 wasm, thread_support=false ──┐  │
│ │ VoiceBridge.gd: poll() раз в кадр, сигналы            │  │
│ │ Api.gd: HTTPRequest /api/songs, /leaderboard, /chal…  │  │
│ │ Boot · Select · Sing · Result · Leaderboard · Duel    │  │
│ └───────────────┬───────────────────────────────────────┘  │
│        JavaScriptBridge (только строки JSON)               │
│ ┌───────────────▼───────────────────────────────────────┐  │
│ │ voice.js: один AudioContext = единые часы             │  │
│ │ minus.mp3→Gain→out    mic→tap(worklet)→Gain0→out      │  │
│ │ tap: pitchy MPM + PCM ─MessagePort→ main (WAV, poll)  │  │
│ └───────────────┬───────────────────────────────────────┘  │
└─────────────────┼─────────────────────────────────────────┘
                  │ /api/*  /media/<id>/*  /c/<id>
┌─────────────────▼─────────────────────────────────────────┐
│ FastAPI: API → StaticFiles(dist/web) на /                  │
│ scoring.py score-v1 ← contracts/scoring.json               │
│ f0: SwiftF0 CPU (default) | torchcrepe CUDA (F0_ENGINE)    │
│ SQLite data/app.db · data/takes/<id>.wav                   │
└─────────────────┬─────────────────────────────────────────┘
                  │ ssh (офлайн, не в игровом рантайме)
┌─────────────────▼─────────────────────────────────────────┐
│ CUDA-сервер: refpipe = UltraSinger + Demucs + cut/compile  │
│ → songs/<id>/ → коммит                                     │
└───────────────────────────────────────────────────────────┘
```
