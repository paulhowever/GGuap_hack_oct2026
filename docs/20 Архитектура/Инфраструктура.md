```

  web/ voice.js voice.mock.js tap.js config.js dev.html lib/ vendor/pitchy.bundle.js mock/ test/
  backend/ app/{main,songs,board,duel,demo,health,ids}.py app/{api,anticheat,core,f0,scoring,store}/ tests/ pyproject.toml uv.lock
```

Не сделано / после хакатона: `backend/app/schemas.py`, `contracts/{reference,result}.schema.json`, `contracts/openapi.json`, `contracts/bridge.md`, `scripts/{export_web,sync_fixtures,dev}.sh`, `deploy/compose.yml` и `deploy/Caddyfile`, `CREDITS.md`, `pipeline/refpipe/importer.py` ([[ADR-022 Импорт трека после хакатона]]), `Dockerfile.cuda`.

**Локально.**
- `make backend` — FastAPI на `:8000` отдаёт `web/` (движок и `dev.html`, без Godot).
- `make dev` — экспорт Godot (`GODOT_PROJECT`, по умолчанию `godot`) в `dist/web`, `make assemble`, затем бэкенд с `KARAOKE_WEB_DIR=dist/web`.
- `make demo` — то же без экспорта: экспорт Godot уже лежит в `dist/web` (скопирован руками).
```
"$GODOT" --headless --path "$GODOT_PROJECT" --export-release "Web" dist/web/index.html
rsync -a --exclude node_modules --exclude test --exclude package.json --exclude package-lock.json web/ dist/web/
cd backend && KARAOKE_WEB_DIR=../dist/web uv run uvicorn app.main:app --host 0.0.0.0 --port 8000
```
FastAPI регистрирует `/healthz`, `/api/v1` и `/c/{id}`, затем `/media` (→ songs/), затем `StaticFiles(KARAOKE_WEB_DIR, html=True)` на `/` (по умолчанию `web/`).

**Онлайн.**
- Запасной вариант, сейчас не используем ([[ADR-017 Объём MVP и решения после ревью]]): VPS 2 vCPU / 4 ГБ, `docker compose up -d` с сервисами api и caddy (`compose.yml` и `Caddyfile` не сделаны).
- Caddyfile: `host { encode zstd gzip; reverse_proxy api:8000 }`. TLS выпускает Caddy, wasm отдаётся сжатым.
- CUDA-сервер не участвует в рантайме.

**CI.**
- backend и pipeline: `uv sync --locked && uv run pytest -m "not gpu" && uv run ruff check . && uv run ruff format --check .`.
- web: `npm ci && npm test && git diff --exit-code vendor/` (закоммиченный бандл pitchy совпадает со сборкой).
- contracts: валидация JSON в `contracts/` и `songs/` (JSON-схем и openapi пока нет).
- CD пока нет: образ в GHCR по тегу `vX.Y.Z` (и `edge` с `main`, [[ADR-013 Устройство бэкенда]]) и выкатка `docker compose pull && up -d` на VPS — после хакатона.
- Экспорт Godot в CI — stretch, артефакт dist собирается на маке.

**Git.**
- Trunk-based: main защищён, ветки `pasha/…`, `max/…`, PR с 1 ревью, squash.
- CODEOWNERS (файла пока нет): `contracts/` → Паша и Макс.
- `.godot/`, `data/`, `dist/` в .gitignore.
- Правила для ИИ-следов:
  - в `.git/info/exclude` у каждого: `CLAUDE.md .mcp.json .claude/ AGENTS.md .cursor/`;
  - локальный нетрекаемый `commit-msg` хук вырезает `Co-Authored-By`;
  - комментариев в коде нет.

**Obsidian.**
- `docs/` tracked: 10-product, 20-contracts (ссылки на contracts/), 30-adr, 40-tasks, 50-songs-licenses, 60-pitch, 90-templates. `.obsidian/workspace*` в ignore.
- ADR: `status/date/deciders` + Контекст, Решение, Альтернативы, Последствия.
- Личные заметки лежат вне репо.
