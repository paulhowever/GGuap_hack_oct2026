**Локально (`make dev`):**
```
"$GODOT" --headless --path godot --export-release "Web" ../dist/web/index.html
rsync -a web/ dist/web/
cd backend && uv run uvicorn app.main:app --port 8000
```
FastAPI регистрирует `/healthz`, `/api/v1` и `/c/{id}`, затем `/media` (→ songs/), затем `StaticFiles("dist/web", html=True)` на `/`.

**Онлайн.**
- Запасной вариант, сейчас не используем ([[ADR-017 Объём MVP и решения после ревью]]): VPS 2 vCPU / 4 ГБ, `docker compose up -d` с сервисами api и caddy.
- Caddyfile: `host { encode zstd gzip; reverse_proxy api:8000 }`. TLS выпускает Caddy, wasm отдаётся сжатым.
- CUDA-сервер не участвует в рантайме.

**CI.**
- backend: `uv sync && uv run pytest -m "not gpu"`.
- contracts: валидация JSON в `contracts/` и `songs/` (JSON-схем и openapi пока нет).
- CD по тегу `vX.Y.Z` (и `edge` с `main`): образ `ghcr.io/paulhowever/gguap_hack_oct2026-api` ([[ADR-013 Устройство бэкенда]]); выкатка на стенд — `docker compose pull && up -d` на VPS.
- Экспорт Godot в CI — stretch, артефакт dist собирается на маке.

**Git.**
- Trunk-based: main защищён, ветки `pasha/…`, `max/…`, PR с 1 ревью, squash.
- CODEOWNERS: `contracts/` → Паша и Макс.
- `.godot/`, `data/`, `dist/` в .gitignore.
- Правила для ИИ-следов:
  - в `.git/info/exclude` у каждого: `CLAUDE.md .mcp.json .claude/ AGENTS.md .cursor/`;
  - локальный нетрекаемый `commit-msg` хук вырезает `Co-Authored-By`;
  - комментариев в коде нет.

**Obsidian.**
- `docs/` tracked: 10-product, 20-contracts (ссылки на contracts/), 30-adr, 40-tasks, 50-songs-licenses, 60-pitch, 90-templates. `.obsidian/workspace*` в ignore.
- ADR: `status/date/deciders` + Контекст, Решение, Альтернативы, Последствия.
- Личные заметки лежат вне репо.
