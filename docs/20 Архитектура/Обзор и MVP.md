# Обзор и MVP

Цепочка: «Godot рисует, JS слушает, бэкенд судит». Игрок выбирает фрагмент, поёт под минус и видит живой питч на нотной дорожке. Затем финальная оценка (SwiftF0 + score-v1) объясняет результат по строкам.

**MVP (в демо на 18.10):**
- 3 своих фрагмента по 20–40 с из народных мелодий.
- unlock-оверлей, калибровка задержки, живой питч pitchy.
- Запись WAV 16 кГц, POST /takes, нотная оценка, автокомпенсация задержки, пересчёт SwiftF0 (это и есть «нейросеть»).
- Экран результата: 3 шкалы, график, разбор по строкам, подсказки.
- Повторы, лидерборд, асинхронная дуэль по ссылке и QR.
- Без сервера: всё локально; QR-дуэль для жюри — временный туннель на площадке (stretch).

**После хакатона** ([[ADR-022 Импорт трека после хакатона]]): импорт «любой трек → караоке» — `refpipe import` (UltraSinger на CUDA-сервере) и POST /songs/import; на защите показываем как следующий шаг.

**Stretch** (go/no-go 15.10):
- scoring.js как живой счёт с паритетом;
- бонус за вибрато;
- DTW;
- LLM-комментатор;
- «призрак» соперника;
- импорт через UI;
- телефон-микрофон по WebRTC;
- torchcrepe/RMVPE;
- QR для зала;
- CI-экспорт Godot.

**Вырезано из брифов:** Redis/RQ и асинхронный provisional/final (SwiftF0 укладывается синхронно), Caddy локально, mkcert, Git LFS, порт scoring.js в MVP.
